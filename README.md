# 👥 Customer Segmentation Using K-Means Clustering

## Project Overview

This project performs customer segmentation using RFM (Recency, Frequency, Monetary) analysis and the K-Means clustering algorithm. The goal is to identify customer groups based on purchasing behavior to support targeted marketing strategies.

## Objectives

- Load customer transaction data.
- Calculate RFM metrics.
- Standardize the dataset.
- Determine the optimal number of clusters.
- Apply K-Means clustering.
- Analyze customer segments.
- Generate business recommendations.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Dataset

**File:** `customer_transactions.csv`

The dataset contains:
- Customer ID
- Transaction Date
- Purchase Amount
- Transaction History

## Project Workflow

1. Import required libraries
2. Load customer data
3. Clean and preprocess data
4. Calculate RFM values
5. Scale features using StandardScaler
6. Determine optimal clusters using the Elbow Method
7. Apply K-Means clustering
8. Assign customer segments
9. Visualize clusters
10. Generate business insights

## Key Insights

- Customers were successfully grouped based on purchasing behavior.
- High-value customers were identified.
- Low-engagement customers were recognized for reactivation campaigns.
- Customer segmentation can improve marketing effectiveness and customer retention.

## Conclusion

This project demonstrates how machine learning techniques such as K-Means clustering can be used to segment customers and support data-driven business decisions.
